# Shield Screen Functionality

The Shield Screen is the primary intervention tool that interrupts impulsive app usage. It acts as a "mindful pause" between the user and a restricted app.

## 1. Mindful Intervention
- **Immediate Interception**: Automatically appears in full-screen when a controlled app is opened or when its session limit is reached.
- **Mindful Messaging**: Displays user-configured headlines and sub-headlines to encourage reflection.
- **Personalized Visuals**: Shows a user-selected image to create a familiar and calm environment.

## 2. Usage Feedback
- **Current App Context**: Clearly displays the name of the app that was just blocked.
- **Today's Usage**: Shows the total time spent on that specific app so far today.
- **Open Attempts**: (Coming soon) Displays how many times the user has tried to open the app today.

## 3. Exit Options
- **Decision to Close**: Provides a prominent "Close" button that takes the user back to the device's Home screen, effectively ending the attempt to use the restricted app.
- **Decision to Open**: Provides an "Open" button to dismiss the shield and proceed to the app, allowing for conscious use after the pause.

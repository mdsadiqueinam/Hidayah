# Home Screen Functionality

The Home Screen serves as the central hub for monitoring and controlling app usage. It provides a high-level overview of screen time and quick access to protection controls.

## 1. Usage Statistics Overview
- **Total Screen Time Monitoring**: Tracks and displays the total time spent across all apps for the current day.
- **Controlled App Usage Monitoring**: Allows switching the view to specifically see total time spent on apps currently under Hidayah's control.
- **Screen Time Status**: Provides a qualitative assessment of usage (e.g., "Excellent", "Good", "Very High") based on the amount of time spent.
- **Usage Percentage**: Calculates and shows what percentage of the active day has been spent on screen.
- **Top Apps List**: Displays the top 3 most used apps for the day with their respective usage durations.
- **Live Updates**: Refreshes usage statistics automatically every minute to ensure data accuracy.

## 2. Protection Controls
- **Global Protection Toggle**: A master switch to enable or disable the tracking and blocking functionality of the app.
- **Pause Protection**: Allows users to temporarily suspend protection for a selected duration (e.g., 5m, 15m, 1h). The protection automatically resumes once the timer expires.
- **Focus Mode**: A dedicated toggle for a stricter focus state (feature currently under development).

## 3. Controlled Apps Management
- **Controlled Apps List**: Displays all apps that the user has specifically chosen to monitor and restrict.
- **Real-time Usage for Controlled Apps**: Shows individual usage time for each controlled app directly in the list.
- **Add App Access**: Provides a way to open a selection dialog or screen to add new apps to the controlled list.
- **App Configuration Navigation**: Clicking on a controlled app navigates the user to its specific settings screen.

## 4. Permission Management
- **Usage Stats Check**: Automatically detects if the "Usage Access" permission is granted.
- **Permission Enforcement**: Displays a prompt or restricts functionality if the necessary system permissions are missing.
